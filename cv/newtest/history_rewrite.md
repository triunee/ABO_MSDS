## 검증

- 다시 쓴 결과 커밋 `e38aeb9`의 파일 트리(`d81c8029…`)는 다시 쓰기 전 마지막 커밋의 트리와 같다. 바뀐 곳이 위 한 줄뿐이라는 뜻이다.
- 다시 쓰기 전 이력은 저장소 밖에 git bundle로 보관한다(비공개).

## 함께 고친 SHA 표기

파일에 적힌 커밋 SHA를 새 SHA로 바꿨다(이 기록과 같은 커밋).

- `cv/newtest/experiment.json`의 `prereg_commit`
- `cv/newtest/hardware.txt`의 `repo_head` · `fixed_commit`. 실행 당시 기록이지만 SHA 값만 바꿨다.
- `cv/newtest/report.md` 머리의 사전 등록 커밋

`experiment.json`이 고정 커밋 뒤에 바뀌었으므로, `scripts/runpod/newtest.sh`를 같은 고정 커밋으로 다시 돌리면 멈춘다. 새 test 추론은 이미 한 번 끝났고 다시 돌리지 않는다.
